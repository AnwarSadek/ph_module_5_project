# 💼 Personal Portfolio Website

A simple personal portfolio website built using HTML and CSS.
This project was created as part of a Programming Hero task to practice
building and styling a portfolio website.

## 🌐 Live Website

🔗 [Live Demo](https://anwarsadek.github.io/ph_module_5_project/)

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Navigation bar
- Hero section
- About Me section
- Skills section
- Education section
- Experience section
- Contact and call-to-action buttons
- Simple portfolio layout

## 🧰 Development Tools

- VS Code
- Git
- GitHub
- Browser Developer Tools

## 🎯 What I Practiced

- HTML5 structure
- CSS styling
- Page layout
- Working with images
- Creating different website sections
- Building a personal portfolio layout

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation or dependencies are required.
